# Workflow

## 入口判断

- 识别人物换装、换装提示词、服饰替换、保脸保背景、单品参考图精修等请求。
- 三步判断图片能力并告知用户：
  1. 判断模型是否支持图像理解：不支持时说明无法解析图片，全程基于文字描述生成，建议换用支持图像理解的模型；
  2. 判断用户是否上传图片：已收到则继续，未收到时说明可基于文字描述生成，建议补传图片以提升还原度；
  3. 若已传图，确认解析是否成功：部分模型声明"无法看到图片"时，告知"已收到图片但当前模型无法实际解析"，按纯文字模式继续。无法解析或未收到图片时不拦截、不死等图片。
- 一次会话只处理一张人物原图。
- 第 1 张图固定作为人物原图。
- 第 2 张及之后的图默认作为单品参考图。
- 如果用户在同一会话里又上传像是新底图的图片，先确认是否要另开会话。
- 如果多张单品参考图的替换映射不明确，先确认每张图对应哪个部位。
- 如果用户指定目标下游模型，记录下来；未指定时默认通用版。

## 场景开关

- `单人单图换装`：默认模式，只处理一张人物原图。
- `多图多人换装`：用户明确多人或多张人像时启用；为每个主体单独建立保留要素和替换清单。
- `换装 + 改姿势`：用户同时要求换装和调整姿态、手脚朝向、站姿或坐姿时启用。
- `换装 + 改姿势 + 保背景`：在改姿势的同时锁定原图背景、场景和光影。
- 默认不启用扩展场景；用户明确说明后再切换。

## 纯文字模式

- 未收到图片或图片无法解析时自动启用，不拦截流程，不停下来等图。
- 回复开头按入口判断对应步骤的说明告知用户。
- 从用户文字中提取：人物形象、目标服饰、姿态、背景或场景。
- 用户未提到的要素按合理默认补全，不做连环追问，并在交付时简要说明做了哪些假设。
- 单品特征仍按 [lexicon](lexicon.md) 的维度清单展开，只依据文字描述，不虚构参考图来源。
- 提示词写成自包含形式：不出现「原图」「参考图中」这类依赖图片的表述。
- 若用户随后补传图片，改按正常带图流程重新生成，并沿用已确认的文字设定。

## 调用模式

- 用户直接调用模式：允许无限轮追问与无限轮精修，直到用户满意。
- Agent 自动调用模式：先产出高质量初稿，最多再做 1 轮澄清；收到下游反馈后再进入精修。
- 若无法判断模式，默认按用户直接调用处理。

## Phase 1

- 先执行入口判断中的三步图片能力判断，并告知用户。
- 校验输入是否满足执行条件，若不满足则停止执行；仅缺图片或图片无法解析不算不满足，自动转入 `纯文字模式` 继续。
- 先识别当前启用的场景开关。
- 若处于 `纯文字模式`，跳过读图步骤，改从用户文字中提取人物、服饰、场景要素，缺失要素按合理默认补全并记录。
- 读取原图并记录需要保留的非替换内容：人物面貌、面部特征、发型、表情、姿态、身材比例、背景、场景、光影、画面风格、原图未指定替换的服饰。
- 如果启用 `多图多人换装`，对每个主体分别建立保留要素、姿势要素和替换清单。
- 如果启用 `换装 + 改姿势`，额外记录目标姿态、肢体朝向、动作关系和构图变化。
- 读取单品参考图并提取完整单品特征：外观、颜色、材质、版型、结构、装饰、品牌标识、纹理质感。
- 建立本次生效的替换清单。

## Phase 2

- 按「保持 / 替换 / 约束」组装通用版提示词。
- 中文版和英文版语义保持一致。
- 中文版使用自然语言；英文版使用地道图像生成术语。
- 若用户未明确某一项，按图像理解结果直接补全，不做冗余追问。
- `纯文字模式` 下，用户未提到的要素按合理默认补全并记录假设；提示词不得出现依赖图片的表述，【保持】改写为人物与场景的一致性设定，【约束】只保留比例、光影统一和自然度等与图片无关的要求。

## Phase 2.5

- 仅在用户指定目标模型时执行。
- 在通用版语义上封装该模型的语法外壳。
- 语义不得增减，只改表达方式、比例写法、负面位、权重位和一致性位。

## Phase 3

- 交付三段式中文提示词和对应英文提示词，按 [prompt-rules](prompt-rules.md) 的格式规则用代码块包裹。
- 若用户指定了模型，额外交付该模型的变体。
- 说明本次替换了哪些单品、保留了哪些内容。
- 提醒用户可将提示词和人物原图一起投喂到下游模型。
- `纯文字模式` 下，交付时再次说明入口判断的结果，并提醒补传图片或换用支持图像理解的模型可显著提升还原度。
- 主动邀请用户根据出图结果继续反馈。

## Phase 4

- 收到反馈后，先把问题归类。
- 只改被点名的段落，保留其余已满意内容不动。
- 常见问题与修改位置：
  - 换错或漏换单品 -> 改【替换】。
  - 面貌、表情、发型走形 -> 强化【保持】和保脸词。
  - 背景或场景被改 -> 强化【保持】中的背景要素。
  - 身材比例拉伸 -> 强化【约束】中的比例和裁剪要求。
  - 材质、颜色、版型不符 -> 改【替换】中的单品特征。
  - 层次或遮挡错乱 -> 改【约束】中的前后关系。
  - 画风或清晰度脱节 -> 补充光影和清晰度匹配要求。
- 继续交付精修后的中英提示词，直到用户满意或结束。
