# Prompt Rules

## 三段式模板

```text
【保持 KEEP】
人物面貌、五官、表情、发型、姿态、身材比例、肤色、未替换服饰、背景、场景、光影、画面风格保持一致。

【替换 REPLACE】
按部位逐个写出指定单品的完整外观、颜色、材质、版型、装饰和结构特征，并明确完全替换对应区域。

【约束 CONSTRAINT】
写明遮挡层次、光影材质与原图匹配、换装区清晰度统一、比例处理方式、整体自然不违和。
```

- 纯文字模式下模板降级使用：【保持】改写为人物形象、姿态、背景和画面的文字设定，不引用原图；【约束】中「与原图匹配」类表述改为「整体自然统一」等不依赖图片的写法。

## 设计规则

- 先写保持，再写替换，最后写约束。
- 原图中未被替换清单覆盖的服饰和环境默认保留。
- 每个被替换单品都要写清楚部位和完整特征。
- 单品特征描述必须可独立复用，不要依赖“参考图中”这类上下文。
- 输出时提示词用 ``` 代码块包裹，中英文分别用独立代码块，便于用户一键复制。
- 中英双语保持同一套语义。
- 用户指定目标模型时，才额外输出语法变体。
- 纯文字模式下，提示词必须自包含：不出现「原图」「参考图中」这类依赖图片的表述，人物、服饰和场景全部用文字写清楚。

## 全局约束

- 正文只用正向表述。
- 只完整替换指定单品，不做局部叠加。
- 不拉伸人物比例。
- 保持原图背景、人物面貌和其他非替换部分。
- 需要目标比例时，写成居中裁剪或目标比例适配。
- 交付前确认款式、层次关系和特征描述完整自然。
- 纯文字模式下，用户未提及的信息按合理默认补全，不虚构参考图来源。
- 精修遵循最小改动、逐轮收敛。
