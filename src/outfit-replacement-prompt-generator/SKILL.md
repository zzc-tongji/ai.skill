# 人物换装提示词生成器

将人物原图和单品参考图整理成可直接投喂下游模型的换装提示词。默认输出中英双语通用版；当用户指定目标模型时，再封装该模型的语法变体。

## 按需加载

- 读 [workflow](references/workflow.md) 以获取会话规则、阶段流程和反馈迭代顺序。
- 读 [prompt-rules](references/prompt-rules.md) 以获取三段式模板、全局约束和输出规范。
- 读 [model-variants](references/model-variants.md) 以获取 Qwen-Image、Seedance、Midjourney、Stable Diffusion、GPT-4o、Gemini 等模型的封装差异。
- 读 [lexicon](references/lexicon.md) 以获取保脸增强词库、负面词库、单品特征维度清单和标准化抽取槽位。

## 运行原则

- 一次会话只处理一张人物原图；同会话后续图片默认作为单品参考图，除非用户确认是新底图。
- 图片处理按 [workflow](references/workflow.md) 入口判断的三步流程执行（模型能力 → 是否传图 → 解析是否成功），每步结果均告知用户。无法解析或未收到图片时不拦截，直接按文字描述生成；可提醒补传图片或换用支持图像理解的模型。
- 输入多张参考图但未说明映射时，先确认每张图对应的替换部位。
- 当用户明确多图多人、换装+改姿势等扩展场景时，按 [workflow](references/workflow.md) 中的场景开关执行；未启用时按单人单底图处理。
- 默认保留人物面貌、表情、发型、姿态、背景、场景、光影和原图未指定替换的部分。
- 只完整替换指定单品，不做局部叠加，不拉伸人物比例。
- 通用版正文用正向自然语言，输出中文和英文两个版本。
- 用户指定目标模型时，额外输出该模型的语法变体。

## 输出骨架

```text
【保持】
人物面貌、五官、表情、发型、姿态、身材比例、背景、场景、光影、风格、未替换服饰保持一致。

【替换】
按部位写入每个指定单品的完整外观、颜色、材质、版型、装饰和结构特征。

【约束】
写明遮挡层次、光影匹配、清晰度统一、居中裁剪或目标比例适配、整体自然不违和。
```

## 精修原则

用户反馈不满意时，只改受影响的段落，并从 [lexicon](references/lexicon.md) 里取最小必要词集补强。
需要负面控制时，按 [model-variants](references/model-variants.md) 的强度分级选词。
